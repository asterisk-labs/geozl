The Julia package has the graph, compress, decompress and profile calls of the Python package and writes the same frames. It works on Julia's own integer and float arrays without conversion.

Install

using Pkg
Pkg.Registry.add(url = "https://github.com/asterisk-labs/AsteriskRegistry")
Pkg.add("GeoZL")

The package calls libgeozl directly. It loads the library named by GEOZL_LIB_PATH, then the one make lib builds in a checkout, then the artifact a release publishes for Linux x86-64 and macOS arm64, downloaded on first use.

using GeoZL

tile = [UInt16(1000 + 3 * (x - 1) + 2 * (y - 1)) for x in 1:256, y in 1:256]

rows = GeoZL.profile(tile)
g = GeoZL.graph(tile, rows[1].graph)
frame = GeoZL.compress(tile, g)
back = GeoZL.decompress(UInt16, frame, size(tile)...)
back == tile                                 # true

Functions

The module exports only GeoZLError, so call the functions as GeoZL.graph and so on. Bad arguments throw ArgumentError, and a recipe, tile or frame the library refuses throws GeoZLError.

profile

GeoZL.profile(x; prior="planar", width=nothing, planes=nothing,
    error=nothing, reps=5, nodata=nothing, verify=false) -> Profile

Compresses and decompresses x with every recipe prior allows and ranks them by ratio. Recipes that do not apply to the input are left out.

priorOne predictor plus the id path, "planar", "med", "delta_w", "delta_n", "average", "wp_static" or "delta_1d". nothing tries every predictor and "none" only id.
repsRound trips per recipe, at least 1. The fastest is kept.
verifyCheck checksums while timing decode.
othersAs in graph.

Returns a Profile, best ratio first.

rows = GeoZL.profile(tile; prior = nothing, reps = 1)
rows[1].graph                                # "med>zigzag>zstd"

graph

GeoZL.graph(x, method; width=nothing, planes=nothing, error=nothing,
    nodata=nothing) -> Graph

Builds a reusable graph for one recipe. The graph fixes the element type and the geometry of every tile compressed with it.

xAn array of UInt8 to UInt64, Int8 to Int64, Float16, Float32 or Float64, possibly with missing. For a lossy graph it fixes the domain later tiles are checked against.
methodA recipe as profile spells it, such as "planar>zigzag>pfor". Python's graph lists them all.
widthRow length in samples. Defaults to size(x, 1) and is required for a vector.
planesStacked images predicted independently. Defaults to the last dimension of an array with three or more, otherwise 1.
errornothing or 0 for lossless, a number for an absolute bound, "1%" for a relative bound, or a full LINEAR, LOG or SQRT recipe, as in Python.
nodataA sentinel. missing values in x are stored as it. NaN holes in a float raster are found without it.
g = GeoZL.graph(tile, "planar>zigzag>pfor"; error = 2)
g.error                                      # "LINEAR:MAX_ERROR=2"

compress

GeoZL.compress(x, g::Graph; coeffs=nothing) -> Vector{UInt8}

Compresses one tile with a graph and returns the frame. The element type must be the graph's, and the geometry is not checked. coeffs, a vector of integer vectors, is stored in the frame header and read back with coeffs.

frame = GeoZL.compress(tile, g; coeffs = [[1, 2, 3], [4]])

decompress

GeoZL.decompress(frame; verify=true, max_output_size=nothing) -> Vector{UInt8}
GeoZL.decompress(T, frame, dims...; nodata=nothing, verify=true,
    max_output_size=nothing) -> Array{T}

Decodes a frame. Without T the result is the raw native bytes. With it, the frame decodes in place into an Array{T} shaped dims, which may also be given as a tuple.

nodataSamples equal to this value become missing, and the result is an Array{Union{Missing,T}}.
verifyCheck the frame checksums.
max_output_sizeRefuse a frame that declares more output bytes than this. Set it for untrusted frames.
back = GeoZL.decompress(UInt16, frame, size(tile))

coeffs

GeoZL.coeffs(frame) -> Union{Nothing,Vector{Vector{Int32}}}

Returns the coefficient vectors stored by compress, or nothing when the frame has none. Only the frame header is read.

GeoZL.coeffs(frame)                          # [[1, 2, 3], [4]]

Types

GraphWhat graph returns, with the fields method, width, planes, eltype, error and nodata. It holds native state and is not thread safe, so build one per task.
ProfileWhat profile returns, a vector of named tuples with the fields graph, bytes, ratio, encode_mbps, decode_mbps and shannon_pct. It also keeps dims, eltype, raw_bytes, width, planes, prior, reps and error.
SampleThe union of the element types GeoZL stores.
GeoZLErrorThrown when the library refuses a recipe, a tile or a frame. Its message carries the library's.

Rasters

The fastest-varying dimension is the row. An array shaped (x, y) or (x, y, band), as Rasters.jl holds a raster, gives the same frame as Python does for (y, x) or (band, y, x). Views and transposes are copied to dense samples first.

missing values are stored as nodata, or as NaN in a float raster. An integer raster with missing values needs a sentinel. A Float16 raster takes no sentinel, though NaN still works.

What it covers

The Julia package covers profile, graph, compress, decompress and coeffs. It has no OpenZL nodes like geozl.lossless and geozl.lossy, no fit_noise and no GPU decode. To share one SQRT curve across products, fit it in Python with fit_noise and pass the recipe it writes.

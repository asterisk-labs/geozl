the Python API

one workflow

Benchmark once, build the graph once, then run every tile of the dataset through it.

signature profile(tile, *, prior="planar", width=None, error=None, reps=5, nodata=None, verify=False) → list[dict]

priorstr · NoneOne predictor plus the id pass. None sweeps them all, "none" sweeps the no-predictor branch alone.
repsintTimes each recipe this many times and keeps the fastest run.
errorstr · NoneMeans what it does in graph, and belongs here too, or the ranking is of graphs nobody will build.
nodatafloat · NoneMeans what it does in graph, for the same reason.
→ rowdictgraph, bytes, ratio, encode_mbps, decode_mbps, shannon_pct. Sorted by ratio.

signature graph(raster, method, *, width=None, error=None, nodata=None) → Graph

rasterndarrayA 2‑D array, or 1‑D with width given. Native byte order, 1, 2, 4 or 8 bytes per element. Only scanned when error is set, to decide whether the recipe can represent the range and whether the graph is built for nonnegative data. It has to cover the product, so pass width too.
methodstrA full recipe string, straight from the profile table. The transposed terminals need 2 to 8 bytes per element, categorical needs 1 or 2.
widthint · NoneThe stride the predictor steps back by, read from raster.shape[-1] when left off. A stride, not a row length: Y*X over a (B, Y, X) cube predicts each band from the one before it.
errorstr · NoneNone is lossless. Otherwise a recipe naming one of LINEAR:, LOG: or SQRT:, prepended to the graph, holding every sample inside the bound it declares.
nodatafloat · NoneThe value that marks a sample as never measured, as GDAL means it. Left off, a float raster holding NaN takes NaN as its own.

signature compress(tile, *, graph) → bytes

tilendarrayOne tile, at the element width the graph was built for. That is the only check. A tile whose rows do not match the graph's stride still compresses, and predicts across a boundary that is not there.
graphGraphThe handle geozl.graph returned. One per stride, dtype and error recipe. Not thread safe, so one per thread.
→ framebytesOne self-describing frame, independent of every other frame the graph wrote.

signature decompress(frame, *, verify=True) → ndarray

framebytesThe frame names its own codecs but not your dtype or shape, so what comes back is flat uint8. Finish with .view(dtype).reshape(shape).
verifyboolChecks the checksums the frame carries, which is what tells a frame that rotted in storage from one that did not. Off buys 1 to 30 per cent of decode and gives up the only warning you get.

the graph model

OpenZL builds a compressor as a directed graph of modular codecs. geozl narrows that freedom down to a closed grid of raster recipes, each one a spatial predictor, a zigzag mapping, an optional byte-lane layout and an encoding backend.

The recipe string records the exact path, for example planar>zigzag>transpose>entropy. profile measures the candidates on your own tile and graph later builds the one you pick, unchanged.

where 56 comes fromEight predictors, counting the no-predictor branch, times seven terminals. A terminal is a layout and a backend together, which is why transpose>zstd and store_lo each count once. The element width closes some off. At one byte the three transposed terminals go and the grid is 32; at four or eight categorical goes and it is 48. Two bytes is the only width that gets all 56.

the stages predictor and layout are optional

inraster tile2-D array, 1 to 8 bytes per sample.
01predictorSubtracts a spatial estimate so the residuals sit near zero.
02zigzagFolds signed residuals onto small unsigned values.
03layoutSplits each sample into byte lanes.
04backendEntropy coder or LZ stage that writes the bytes. categorical reads the stream first and picks one.
outframeOne self-describing OpenZL frame.

Every recipe here is lossless. Setting error prepends a quantisation step ahead of the predictor, which is the only stage that discards anything.

profile the selection step

profile runs a round trip with every recipe that applies to the tile, five reps each with the fastest kept, and ranks the results by ratio. Each row carries the recipe string, the ratio, both throughputs and the distance to the Shannon floor.

Run it once, on a tile that represents the dataset. The chart is why the ranking is not the whole answer: the best ratio is rarely the fastest decode, so pick from the Pareto front.

python · benchmark one representative tile
rows = geozl.profile(
    tile, prior=None, reps=5
)
best = rows[0]["graph"]

graph and compress the production step

profile chooses and graph builds. Both run once. compress is the only call that runs on every tile.

graph builds the recipe exactly as named, with no search and no fallback, and holds the finished DAG. Building the DAG is a fixed cost paid once instead of once per tile, and the same tile through the same handle always gives the same frame.

profile once, build once, compress every tile same data family

oncegraphBuilds that recipe and holds it.
per tilecompressOne pass through the handle.
per tileframeDeterministic, and independent of the others.
python · choose once, build once, run many times
best = geozl.profile(tile, prior=None)[0]["graph"]
g = geozl.graph(tile, best)

for tile in tiles:
    frame = geozl.compress(tile, graph=g)
524.3 kB → 116.5 kB 4.50×

error bounded-error compression

Set error to trade exact reconstruction for a smaller frame under a hard per-sample bound, verified on every sample before the frame is written. None stays lossless. Pick the quantizer by how the measurement error grows, and add ,STORE=VALUES to write the reconstruction instead of the index.

linear · elevation|x − x̂| ≤ V log · SAR backscatter|x − x̂| ≤ P% of x sqrt · optical radiance|x − x̂| ≤ V·σ(x), σ² = a + b·x

For SQRT, fit the noise curve once over the whole product with geozl.lossy.fit_noise(stack) and put a and b in every recipe, so every tile lands on one grid. A recipe without them is fit from whatever raster graph was handed, and two tiles fit separately rebuild differently on their shared boundary. The knee of the curve below is where more error stops buying much more compression.

frame size vs. allowed error
1knee8.81×The knee is near ±2.5 m: 59.5 kB, about half the lossless frame.

decompress get the array back

The frame names every codec it used, so decompress takes the bytes and nothing else. It undoes the codecs in reverse, checks the checksums the frame carries, and returns a flat uint8 array.

Dtype and shape are not properties of the bytes, so you finish with .view and .reshape. A lossless recipe returns the input bit for bit. With error set, every sample comes back inside the bound.

python · restore the raster
back = geozl.decompress(frame)
back = back.view("int16").reshape(512, 512)
(512, 512) int16

complete workflow measure, pick, run, restore

python
rows = geozl.profile(tile, prior=None)
best = rows[0]["graph"]

g = geozl.graph(tile, best, error="LINEAR:MAX_ERROR=4")
frame = geozl.compress(tile, graph=g)
back = geozl.decompress(frame).view("int16").reshape(512, 512)

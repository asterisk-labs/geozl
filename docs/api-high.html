The high-level API has five calls.

profile ranks recipes for a tile.

graph builds a reusable graph.

compress returns a frame.

decompress returns flat bytes.

the Python API

one workflow

One tile selects the pipeline. Every matching tile reuses it.

signature profile(tile, *, prior="planar", width=None, planes=None, error=None, reps=5, nodata=None, verify=False) → ProfileResults

priorstr · NonePredictor filter. None tries all; "none" disables prediction.
widthint · NoneRow length; defaults to tile.shape[-1].
planesint · NoneStack count; defaults to B for (B, Y, X).
repsintTimed runs per recipe.
errornumber · str · NoneAbsolute number, relative percentage or full recipe; zero is lossless.
nodatascalar · NoneMissing-value sentinel.
→ resultProfileResultsList-like rows sorted by ratio; print(rows) includes the input and settings.

signature graph(raster, method, *, width=None, planes=None, error=None, nodata=None) → Graph

rasterndarrayNative-order array; 1, 2, 4 or 8 bytes per sample.
methodstrRecipe returned by profile.
widthint · NoneRow length; defaults to raster.shape[-1].
planesint · NoneStack count; row predictors reset between planes.
errornumber · str · None2 is absolute, "1%" is relative, and zero is lossless.
nodatascalar · NoneSentinel; omitted NaNs are detected automatically.

signature compress(tile, *, graph, coeffs=None) → bytes

tilendarrayMatching dtype; geometry is not checked.
graphGraphReusable graph; not thread-safe.
coeffssequence · NoneInteger vectors stored with this frame and returned by coeffs.
→ framebytesSelf-describing OpenZL frame.

signature decompress(frame, *, verify=True, max_output_size=None) → ndarray

framebytesReturns flat uint8.
verifyboolChecks frame checksums.
max_output_sizeint | NoneCeiling on the bytes allocated. The size is read from the frame, so pass one for untrusted input.

signature coeffs(frame) → tuple | None

framebytesRead from the frame header; the payload is not decompressed.
→ vectorstuple · NoneOne tuple of int32 per vector, or None when absent. Vector meaning is defined by the producer and consumer.

Coefficient vectors are application-defined integer metadata. GeoZL preserves their values and ordering without interpreting them.

metadata = ((7, -3, 11), (2, 5))
frame = geozl.compress(tile, graph=g, coeffs=metadata)

assert geozl.coeffs(frame) == metadata

the graph model

A graph is a reusable codec pipeline. profile finds a recipe; graph builds it unchanged.

up to 56 valid pathsplanar>zigzag>transpose>entropy

Recipes are lossless unless error adds quantisation before the predictor.

profile the selection step

profile benchmarks every valid recipe on one representative tile and ranks them by ratio.

The result behaves like a list. print(rows) shows the input geometry, benchmark settings and table together.

Run it once. Pick from the Pareto front: the smallest frame is not always the fastest decode.

python · benchmark one representative tile
rows = geozl.profile(
    tile, prior=None, reps=5
)
print(rows)
best = rows[0]["graph"]

compression ratio vs decode speed 48 candidateshover a square pareto front dominated

error bounded-error compression

error trades exact values for a smaller frame under an explicit per-sample bound. Pass 2 for a linear absolute bound or "1%" for a logarithmic relative bound. None and zero stay lossless.

Full LINEAR, LOG and SQRT recipes remain available when you need their advanced options.

Build from data spanning the product; later tiles outside that domain are rejected.

linear · elevation|x − x̂| ≤ V log · SAR backscatter|x − x̂| ≤ P% of x sqrt · optical radiance|x − x̂| ≤ V·σ(x), σ² = a + b·x

SQRT: fit noise once with geozl.lossy.fit_noise(stack), then reuse a and b across tiles.

decompress get the array back

decompress(frame) verifies the self-describing frame and returns flat uint8.

Restore dtype and shape with .view and .reshape. Lossless frames round-trip exactly; lossy frames respect their bound.

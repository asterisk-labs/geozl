API

  • Python package geozl on PyPI. C headers in core/include/geozl.

Four Python calls cover most use. profile measures candidate recipes on a tile, graph builds one, compress runs tiles through it and decompress returns the bytes. The notebook runs them on a DEM tile.

import numpy as np
import geozl

y, x = np.mgrid[0:256, 0:256]
tile = (1000 + 3 * x + 2 * y).astype(np.int16)

rows = geozl.profile(tile)                  # candidates, best ratio first
g = geozl.graph(tile, rows[0]["graph"])     # build the chosen recipe once
frame = geozl.compress(tile, graph=g)       # bytes
back = geozl.decompress(frame).view(tile.dtype).reshape(tile.shape)
assert np.array_equal(back, tile)

Python

Everything below is in geozl.__all__. Arrays go in as NumPy arrays or anything np.ascontiguousarray accepts, in native byte order, at 1, 2, 4 or 8 bytes per sample.

profile

geozl.profile(tile, *, prior='planar', width=None, planes=None, error=None,
    reps=5, nodata=None, verify=False) -> ProfileResults

Compresses and decompresses tile with every candidate recipe and returns one row per recipe, sorted by compression ratio. Timing runs in C and keeps the fastest of reps round trips.

priorA predictor name, "planar", "med", "delta_w", "delta_n", "average", "wp_static" or "delta_1d", profiles that predictor and the id path. None profiles every predictor and "none" only id.
widthRow length in samples. Defaults to the last axis and is required for a 1d array.
planesStacked images predicted independently. Defaults to the first axis of an array with three or more dimensions, otherwise 1.
errorThe error budget, see error budgets. None is lossless.
repsRound trips timed per recipe, at least 1.
nodataA sentinel value to mask. NaNs are masked without it on a float tile.
verifyVerify checksums while timing decode. The frames always carry them.

Returns a ProfileResults. Each row is a dict with graph, bytes, ratio, encode_mbps, decode_mbps and shannon_pct, the frame size against the order 0 byte entropy of the tile. A recipe that fails on the tile is left out.

Raises ValueError for reps below 1, an unknown prior, a bad error budget or geometry, and a dtype that is not native byte order or not 1, 2, 4 or 8 bytes. Raises RuntimeError when every recipe fails.

graph

geozl.graph(raster, method, *, width=None, planes=None, error=None,
    nodata=None) -> Graph

Builds a reusable compression graph for one recipe. The graph owns its compression context and is not thread safe, so use one per thread.

rasterA representative tile. It fixes the dtype and, for a lossy budget, the domain later tiles must stay inside. Build it from data spanning the product.
methodA recipe as profile spells it, <predictor>>zigzag><terminal>, delta_1d><terminal> or id><terminal>. The predictors are delta_w, delta_n, planar, med, average and wp_static. The terminals are entropy, field_lz, zstd, categorical, transpose>entropy, transpose>zstd, pfor, lanes and sparse.
width, planesAs in profile. Row predictors reset at each plane. Pass width=Y*X, planes=1 to predict across bands.
errorSee error budgets.
nodataA sentinel to mask, read at the raster dtype. Without it a float raster that holds NaNs gets a NaN mask.

Returns a Graph.

Raises ValueError for an empty method, a bad budget, geometry or dtype, a lossy budget on a dtype the quantizers lack, such as complex, and a sentinel on float16. Raises RuntimeError when the C library refuses the recipe, such as an unknown method, a terminal that does not take the sample width, or a bound finer than the dtype resolves.

g = geozl.graph(tile, "planar>zigzag>pfor", error=2)
g.error                                     # 'LINEAR:MAX_ERROR=2'

compress

geozl.compress(tile, *, graph, coeffs=None) -> bytes

Compresses one tile with a prepared graph and returns the frame. The dtype must equal the graph's. The geometry is not checked against the graph.

graphA Graph from geozl.graph.
coeffsInteger vectors stored in the frame header, read back with coeffs. At most 255 non-empty vectors of int32 values within 10,000 packed bytes. GeoZL gives them no meaning.

Raises TypeError when graph is not a Graph or a coefficient is not an integer. Raises ValueError for a dtype mismatch or coefficients past the limits. Raises RuntimeError when compression fails, including a lossy tile outside the graph's domain. That is a negative sample where the raster had none, a float magnitude above the raster's under LINEAR, or a value outside the fitted range under SQRT.

decompress

geozl.decompress(frame, *, verify=True, max_output_size=None) -> ndarray

Decodes a frame into a flat, 8-byte aligned uint8 array. The frame stores no dtype or shape, so restore them with .view(dtype).reshape(shape).

verifyCheck the frame checksums. Set False to skip them.
max_output_sizeRefuse a frame that declares more output bytes than this. OpenZL may still allocate intermediate streams while decoding.

Raises ValueError when max_output_size is negative, not finite or below the declared size. Raises RuntimeError for an unreadable or corrupt frame.

coeffs

geozl.coeffs(frame) -> tuple[tuple[int, ...], ...] | None

Returns the coefficient vectors stored by compress, or None when the frame has none. Only the frame header is read.

Raises RuntimeError for an unreadable frame or one older than OpenZL format 22.

frame = geozl.compress(tile, graph=g, coeffs=[[1, 2, 3], [4]])
geozl.coeffs(frame)                         # ((1, 2, 3), (4,))

Error budgets

The error argument of profile and graph takes a number, a percentage or a full recipe. Near-lossless explains the three quantizers.

None, 0Lossless. So is any recipe whose bound is zero.
2.5LINEAR:MAX_ERROR=2.5, an absolute bound |x − x̂| ≤ 2.5.
"1%"LOG:MAX_ERROR=1%, a relative bound |x − x̂| ≤ 0.01 |x|. Between 0% and 100%.
recipeLINEAR:MAX_ERROR=V, LOG:MAX_ERROR=P% or SQRT:MAX_ERROR=kN, with |x − x̂| ≤ k √(a + b x). SQRT fits a and b from the raster unless the recipe carries both A= and B=, as Noise.recipe writes them.

A boolean, a negative or non-finite number and any other string raise ValueError.

Graph

geozl.Graph(handle, *, method, width, planes, dtype, itemsize, error,
    nodata)

The handle geozl.graph returns. Its constructor takes the C graph and is not meant to be called directly. Its attributes are method, width, planes, dtype, itemsize, error, the normalized recipe or None, and nodata.

ProfileResults

geozl.ProfileResults(*, shape, dtype, raw_bytes, width, planes, prior, reps,
    error)

A list of profile rows that also keeps the input and settings as attributes of those names. print(rows) shows them above the table.

simd_info

geozl.simd_info() -> SimdInfo

Returns a dict with the SIMD paths compiled in (built), those the CPU supports (cpu) and the one in use (active). The names are scalar, sse2, avx2 and neon. Set GEOZL_SIMD to one of them before import to cap the active path.

register_decoders

geozl.register_decoders(dctx) -> None

Registers every GeoZL decoder in an openzl.ext.DCtx, for frames built with the low-level codec classes. Raises ModuleNotFoundError when the openzl package is missing.

__version__

The installed version string, or "0+unknown" when the package metadata is missing.

geozl.lossless

The lossless codecs as openzl.ext nodes, for graphs the recipe grid does not cover. The module needs the openzl package. Where OpenZL publishes no wheel, geozl.lossless and geozl.lossy are absent from geozl and the calls above still work.

geozl.lossless.DeltaW(width, planes=1)
geozl.lossless.DeltaN(width, planes=1)
geozl.lossless.Planar(width, planes=1)
geozl.lossless.PlanarZigzag(width, planes=1)
geozl.lossless.PlanarZigzagPfor(width, planes=1)
geozl.lossless.Med(width, planes=1)
geozl.lossless.MedZigzag(width, planes=1)
geozl.lossless.Average(width, planes=1)
geozl.lossless.WpStatic(width, planes=1)
geozl.lossless.Deinterleave()
geozl.lossless.Nodata(width, value=None, dtype=None, radius=None)
geozl.lossless.Pfor()

Each instance is called as node(compressor, successor) and returns an openzl.ext.GraphID, so a graph is built from the tail. Nodata takes (compressor, values_successor, mask_successor), and Deinterleave sends both lanes to its one successor. PlanarZigzagPfor and Pfor emit a serial stream. DeltaW raises ValueError for planes other than 1.

Each codec has a decoder class of the same name plus Decoder, such as PlanarDecoder, all registered by register_decoders. The codec pages describe what each one computes.

NodataSplits holes into a validity mask and fills them. Pass value and dtype together for a sentinel, or neither to mask NaNs. radius is the largest error of later stages, 0 for a lossless graph.
WpStaticFits four weights and a shift per stream, shared by all planes.
geozl.lossless.component_dtype(dtype)
geozl.lossless.nodata_bits(value, dtype) -> int

component_dtype returns the real dtype of a complex dtype, float32 for complex64. nodata_bits returns a sentinel's bit pattern as an unsigned integer, the form Nodata stores.

geozl.lossless.pfor.bound(nb_elts, elt_width)
geozl.lossless.pfor.encode(values)
geozl.lossless.pfor.decode(packed, nb_elts, dtype)
geozl.lossless.planar_zigzag_pfor.bound(nb_elts, elt_width)
geozl.lossless.planar_zigzag_pfor.encode(values, width, planes=1)
geozl.lossless.planar_zigzag_pfor.decode(packed, nb_elts, dtype, width,
    planes=1)

Raw payload helpers without an OpenZL frame. bound is the worst case size, or 0 for a refused geometry. decode raises ValueError on a corrupt stream.

import numpy as np
import openzl.ext as zl
import geozl

y, x = np.mgrid[0:256, 0:256]
tile = (1000 + 3 * x + 2 * y).astype(np.uint16)

c = zl.Compressor()
c.select_starting_graph(
    geozl.lossless.Planar(256)(c, zl.nodes.Zigzag()(c, zl.graphs.Entropy()(c))))
cctx = zl.CCtx()
cctx.ref_compressor(c)
cctx.set_parameter(zl.CParam.FormatVersion, zl.MAX_FORMAT_VERSION)
frame = cctx.compress([zl.Input(zl.Type.Numeric, tile.reshape(-1))])

dctx = zl.DCtx()
geozl.register_decoders(dctx)
back = dctx.decompress(frame)[0].content.as_nparray().view(np.uint16)
assert np.array_equal(back.reshape(tile.shape), tile)

geozl.lossy

geozl.lossy.QuantLinear(recipe, dtype)
geozl.lossy.QuantLog(recipe, dtype)
geozl.lossy.QuantSqrt(recipe, dtype)

The three quantizers as nodes, called like the lossless ones. recipe is a full recipe string such as "LINEAR:MAX_ERROR=0.5". The grid is resolved from each stream they encode, so there is no shared domain or cross-tile check as in geozl.graph. A QuantSqrt recipe must carry A= and B=.

The compression context must disable the content checksum with cctx.set_parameter(zl.CParam.ContentChecksum, 2). Without it, or with a SQRT recipe lacking its curve, cctx.compress raises RuntimeError. The constructors raise ValueError for a recipe they cannot parse or a dtype without a kernel. The decoders are QuantLinearDecoder, QuantLogDecoder and QuantSqrtDecoder.

geozl.lossy.fit_noise(data)
geozl.lossy.Noise(a, b, blocks, bins, range, colin, resid)
geozl.lossy.Noise.recipe(max_error)

fit_noise fits variance = a + b x to a 2d raster, an (N, H, W) stack or a sequence of 2d rasters of one dtype, and returns a frozen Noise. The other fields are fit diagnostics. Noise.recipe(k) returns the SQRT recipe for a bound of k sigmas with the fitted curve, so one grid serves every tile.

fit_noise raises ValueError for the wrong dimensions, mixed dtypes or a side under 10 samples, and RuntimeError when the data supports no fit, such as a constant raster. recipe raises ValueError for a bound that is not positive.

rng = np.random.default_rng(0)
counts = rng.poisson(100, (256, 256)).astype(np.uint16)
noise = geozl.lossy.fit_noise(counts)
g = geozl.graph(counts, "planar>zigzag>pfor", error=noise.recipe(2))

C

The C library holds everything the Python calls use. Functions that return int return 0 on success and otherwise a ZL_ErrorCode, with a message written to errCtx when it is not NULL. The headers are the supported source API, and before 1.0 they may change in any release, as C API stability sets out.

typedef enum {
  GEOZL_DT_U8 = 0, GEOZL_DT_U16 = 1, GEOZL_DT_U32 = 2, GEOZL_DT_U64 = 3,
  GEOZL_DT_I8 = 4, GEOZL_DT_I16 = 5, GEOZL_DT_I32 = 6, GEOZL_DT_I64 = 7,
  GEOZL_DT_F16 = 8, GEOZL_DT_F32 = 9, GEOZL_DT_F64 = 10
} geozl_dtype;

typedef enum {
  GEOZL_NODATA_NONE = 0,
  GEOZL_NODATA_NAN = 1,
  GEOZL_NODATA_VALUE = 2
} geozl_nodata_mode;

A dtype argument takes a geozl_dtype code, which is part of the wire format. NaN mode applies to floating point data and value mode masks the sentinel given as bits.

One-shot compression

int geozl_2d_compress_c(const char *method, uint32_t width, uint32_t planes,
                        const char *error, int dtype, int nodataMode,
                        uint64_t nodataBits, const void *src,
                        size_t numElts, size_t eltWidth, void *dst,
                        size_t dstCapacity, size_t *outSize, char *errCtx,
                        size_t errCtxSize);

Builds the graph for a recipe and compresses src with it in one call. error is NULL or "" for lossless, or a LINEAR, LOG or SQRT recipe. nodataBits holds the sentinel's low eltWidth bytes and is read only in value mode.

size_t geozl_2d_frame_dsize_c(const void *frame, size_t frameSize);

Returns the decompressed size in bytes, or 0 for an unreadable frame. An empty frame also reports 0.

int geozl_2d_decompress_c(const void *frame, size_t frameSize, void *dst,
                          size_t dstCapacity, size_t *outSize, int verify,
                          char *errCtx, size_t errCtxSize);

Decompresses a frame into dst, which should be 8-byte aligned for numeric output. verify set to 0 skips checksum verification.

int geozl_2d_bench_c(const char *method, uint32_t width, uint32_t planes,
                     const char *error, int dtype, int nodataMode,
                     uint64_t nodataBits, const void *src, size_t numElts,
                     size_t eltWidth, size_t reps, int checksum, int verify,
                     size_t *compSize, double *encSec, double *decSec,
                     char *errCtx, size_t errCtxSize);

Times reps round trips of one recipe and reports the frame size and the fastest encode and decode, in seconds. checksum controls the frame checksums and verify their check during decode.

int geozl_2d_grid_c(const char *method, size_t eltWidth, char *names,
                    size_t stride, size_t maxNames, size_t *outCount);

Writes the recipe names profile sweeps, one per stride-byte slot, for the sample width. method takes a prior as in profile, with "" for all predictors. Returns -1 for an unknown prior.

Graphs

typedef struct geozl_2d_graph_s geozl_2d_graph;
int geozl_2d_graph_open_c(geozl_2d_graph **out, const char *method,
                          uint32_t width, uint32_t planes,
                          const char *error, int dtype, int nodataMode,
                          uint64_t nodataBits, const void *src,
                          size_t numElts, size_t eltWidth, char *errCtx,
                          size_t errCtxSize);

Opens a reusable graph, the C side of geozl.graph. src fixes the lossy domain, and later tiles outside it are refused before compression.

int geozl_2d_compress_graph_c(geozl_2d_graph *g, const void *src,
                              size_t numElts, void *dst, size_t dstCapacity,
                              size_t *outSize, char *errCtx,
                              size_t errCtxSize);
int geozl_2d_compress_coeffs_c(geozl_2d_graph *g, const void *src,
                               size_t numElts, const void *coeffs,
                               size_t coeffsSize, void *dst,
                               size_t dstCapacity, size_t *outSize,
                               char *errCtx, size_t errCtxSize);

Compress one tile with an open graph, which supplies the sample width. The second attaches a blob from geozl_coeffs_pack to this frame only. NULL and 0 write a frame without one. A declared sentinel is left out of the domain check.

void geozl_2d_graph_close_c(geozl_2d_graph *g);

Frees a graph. Accepts NULL.

int geozl_2d_frame_coeffs_c(const void *frame, size_t frameSize, void *dst,
                            size_t dstCapacity, size_t *outSize);

Copies a frame's coefficient blob without decoding the payload. Returns 0 on success, -1 when the frame has none and a positive ZL_ErrorCode on failure, ZL_ErrorCode_formatVersion_unsupported for a frame older than GEOZL_COEFFS_FORMAT_MIN. Pass dst as NULL to query the size.

Nodes

ZL_Report geozl_register_decoders(ZL_DCtx *dctx);
int geozl_owns_ctid(uint32_t ctid);
int geozl_ctid_is_lossy(uint32_t ctid);

The first registers every GeoZL decoder in an OpenZL decompression context. The others report whether a codec id lies in GeoZL's reserved range and in its lossy part. The ids are the GeozlCtid values in geozl/ctids.h.

Build an encoder node in a compressor, or return ZL_NODE_ILLEGAL. width is in samples and planes counts stacked images, with an invalid plane layout treated as one plane. lanes splits samples into byte lanes coded with PivCo or PFOR, and planar_zigzag_lanes runs planar and zigzag first.

                                  const quant_linear_params *params,

                                const quant_sqrt_params *params, int dtype);

Build a quantizer node from resolved parameters, the structs in geozl/quant_*_params.h.

ZL_NodeID geozl_node_nodata(ZL_Compressor *c, uint32_t width,
                            geozl_nodata_mode mode, uint64_t valueBits,
                            int dtype, double radius);

Builds a NoData node. In value mode dtype lets it guard samples a lossy stage could move onto the sentinel. radius is that stage's largest error, 0 on a lossless path and INFINITY when unknown. In NaN mode a radius of 0 keeps every NaN's bits and any other marks every NaN as a hole.

Coefficients

size_t geozl_coeffs_size(const uint32_t *counts, size_t nbVecs);
size_t geozl_coeffs_pack(void *dst, size_t dstCapacity,
                         const int32_t *const *vecs, const uint32_t *counts,
                         size_t nbVecs, char *err, size_t errSize);

geozl_coeffs_size returns the packed size of nbVecs vectors, or 0 for an invalid shape. geozl_coeffs_pack packs them into dst and returns the bytes written, or 0 on error. The limits are GEOZL_COEFFS_MAX_VECS (255) vectors and GEOZL_COEFFS_MAX_BYTES (10000) bytes. These functions do not depend on OpenZL.

int geozl_coeffs_parse(const void *src, size_t srcSize, int32_t *dst,
                       size_t dstValues, uint32_t *counts, size_t maxVecs,
                       size_t *outVecs, size_t *outValues);

Reads a blob into dst, vectors back to back, and their lengths into counts. Returns 0 on success, 1 when src is not a GeoZL blob, -1 when it is invalid and -2 when a buffer is too small, with the sizes still written. Call with both buffers NULL to learn the sizes first.

GPU decode

The decoder in geozl/gpu.h writes frames straight into device memory on a GPU. CUDA and Metal are the first backends. GPU API walks through a full call.

#define GEOZL_GPU_DEVICE_CUDA 2     // DLPack device types
#define GEOZL_GPU_DEVICE_METAL 8

typedef struct GeozlGpu GeozlGpu;
typedef struct GeozlGpuMemory GeozlGpuMemory;

typedef struct {
  const void *data;
  size_t size;
  size_t decodedBytes;
} GeozlGpuFrame;

typedef struct {
  size_t frame;
  size_t source;
  size_t sourceRow;
  size_t sourceStep;
  size_t destination;
  size_t destinationRow;
  size_t destinationStep;
  uint32_t width;
  uint32_t rows;
} GeozlGpuCopy;

typedef struct {
  void *memory;
  size_t offset;
  size_t bytes;
  void *stream;
} GeozlGpuTarget;

A GeozlGpuFrame is the compressed bytes and the exact size they decode to. A GeozlGpuCopy moves rows rows of width samples from one decoded frame into the target, with offsets and strides in bytes. A GeozlGpuTarget names the device memory, the byte offset and writable bytes after it, and the stream the work joins.

int geozl_gpu_available(int deviceType);

Returns nonzero when this build drives the device type.

GeozlGpu *geozl_gpu_create(int deviceType, int device, size_t threads,
                           size_t maxDecodedBytes, int verifyChecksums,
                           char *error, size_t errorCapacity);
void geozl_gpu_destroy(GeozlGpu *gpu);

Creates a decoder on one device, or returns NULL with a message. threads caps the host threads of one decode, with 0 meaning one, and maxDecodedBytes caps the decoded bytes of one call and must be nonzero. A decoder serves one call at a time.

int geozl_gpu_decode(GeozlGpu *gpu, const GeozlGpuFrame frames[],
                     size_t frameCount, const GeozlGpuCopy copies[],
                     size_t copyCount, size_t sampleBytes,
                     size_t elementBytes, const GeozlGpuTarget *target,
                     const uint8_t forceHost[], char *error,
                     size_t errorCapacity);

Decodes the frames and runs the copies into the target. Single-chunk pfor and lanes frames of 1 or 2-byte samples expand on the device, and the rest decode on the host and upload. forceHost is NULL or one byte per frame, nonzero to send that frame through the host.

int geozl_gpu_synchronize(GeozlGpu *gpu, char *error, size_t errorCapacity);

Waits for queued work and reports its errors. On CUDA geozl_gpu_decode returns once work is queued, so keep the target alive until this returns. Metal finishes inside the decode call.

GeozlGpuMemory *geozl_gpu_alloc(GeozlGpu *gpu, size_t bytes, char *error,
                                size_t errorCapacity);
void *geozl_gpu_pointer(const GeozlGpuMemory *memory);
void geozl_gpu_free(GeozlGpuMemory *memory);

Allocate and free caller-owned device memory for a target. geozl_gpu_pointer returns the device handle to pass as GeozlGpuTarget.memory.

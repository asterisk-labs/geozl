nodata

The samples that were never measured.

A nodata sample is not a small value, it is the absence of one. Left where it sits, every cloud edge and every scene border becomes a cliff the predictor has to encode. nodata takes them out first. Outcome 0 is the raster with each hole filled by the last valid sample on its row, so what runs next sees a flat run instead of a jump. Outcome 1 is a validity mask, one byte per sample, following GDAL where 0 discards and 255 keeps. The original bit pattern rides in the header and comes back on decode, exact down to the NaN payload. A tile with nothing missing sends no mask at all, and one where nothing was measured sends neither stream. The node sits at the head of the graph, ahead of any quantizer, because a quantizer has no sane answer for a sample that was never measured.

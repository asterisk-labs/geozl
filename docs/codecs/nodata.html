nodata

Split the nodata out before anything predicts across it.

Splits the raster in two. Outcome 0 is the raster with each nodata hole filled from the previous valid sample on its row, or the row above at a row start, so downstream stages see a flat run instead of a jump. Outcome 1 is a validity mask, one byte per sample, 0 discards and nonzero keeps. The original bit pattern is stored in the header and restored exactly on decode, NaN payload included. A clean tile still pays for its mask, so use it only on tiles that contain nodata, ahead of any quantizer.

nodata

The samples that were never measured.

A nodata sample marks an absence, not a measurement. Left where it sits, every cloud edge and every scene border becomes a cliff the predictor has to encode. nodata takes them out first. Outcome 0 is the raster with each hole filled by the last valid sample on its row, or the one above where a hole opens the row, so what runs next sees a flat run instead of a jump. Outcome 1 is a validity mask, one byte per sample, following GDAL, where 0 discards and any nonzero byte keeps. The original bit pattern rides in the header and comes back on decode, exact down to the NaN payload. A clean tile still pays for its mask, so the node belongs only in the graphs built for tiles that need it. It goes at the head of those, ahead of any quantizer, which has no sane answer for a sample that was never measured.

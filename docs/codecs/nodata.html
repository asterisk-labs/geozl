nodata

Split the nodata out before anything predicts across it.

Splits the raster into filled values and a validity mask. A hole takes the previous valid sample on its row, or the sample above at a row start, so predictors do not cross a jump. Mask byte 0 marks nodata; nonzero keeps the value. The header stores one nodata bit pattern. NaN mode uses the first payload for every masked NaN. Use this codec ahead of a quantizer, and only on tiles that contain nodata.

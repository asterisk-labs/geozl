quant_log

A fixed fraction, not a fixed amount.

A relative bound. A value of 8000 gets the same one per cent of slack as a value of 8, which puts the levels at powers of a fixed ratio, a uniform grid in log2. Zero takes index zero and comes back exact. The grid is fixed by the recipe alone, never by the tile, so a scene cut at one chunk size and again at another gives the same indices.

quant_log

A fixed fraction, not a fixed amount.

A relative bound. A value of 8000 gets the same one per cent of slack as a value of 8. Ask for the gap between levels to be proportional to the value and the levels come out as powers of a fixed ratio, which is a uniform grid once you take the log. Everything is in log2 because the integer part of log2 of a float is its exponent field, exact and free. Zero has no magnitude to place, so it takes index zero and comes back exact. Nothing about the grid comes from the tile, not the anchor and not the step, so a scene cut at one chunk size and again at another gives the same numbers. Both transcendentals are written out in plain IEEE arithmetic rather than called from libm, which is not correctly rounded, so a frame written on one machine rebuilds the same index on another.

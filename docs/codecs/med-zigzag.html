med_zigzag

The fused version of MED + Zigzag.

MED: P = median(W, N, W + N − NW), r = sample − P
Zigzag: z = (r << 1) ^ (r >> (bits − 1))
Example: r = [0, −1, 1, −2, 2] → z = [0, 1, 2, 3, 4]

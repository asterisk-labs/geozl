planar_zigzag

The fused version of Planar + Zigzag.

Planar: r = sample − (W + N − NW)
Zigzag: z = (r << 1) ^ (r >> (bits − 1))
Example: r = [0, −1, 1, −2, 2] → z = [0, 1, 2, 3, 4]

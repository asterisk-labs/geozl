wp_static

JPEG XL's weighted predictor, with the weights held fixed.

JPEG XL's self-correcting weighted predictor retunes its weights on every sample from recent errors. This codec trains them once per tile and freezes them, leaving a fixed linear function of five causal neighbours, W plus a kernel K over N, NW, NE and NN. W enters with weight one, so P = W + K and a row still decodes as a prefix sum. The four kernel weights and a right shift travel in the header, and with the default weights it reduces to planar.

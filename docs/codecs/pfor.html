pfor

Spend only the bits each block needs.

pfor stores integers in blocks of 256. Within each block, most values use the same small number of bits. If a value needs more, only its extra bits go into a short exception list. Use it as the last codec in a recipe when the remaining values are small but do not repeat, and fast decoding matters more than squeezing out the smallest possible file.

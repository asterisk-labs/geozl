On the CPU, frames decode in RAM

tile = geozl.decompress(frame).view(dtype).reshape(shape)

The frame stores no dtype or shape. The caller keeps them, as Rumi does in its external header.

GeoZL11 / 13

On a GPU, frames decode in GPU memory

geozl_gpu_decode(gpu, frames, n, copies, m, sampleBytes, elementBytes, &target, NULL, err, len);

Frames whose recipe ends in pfor or lanes expand on the GPU. Any other frame decodes on the CPU and is copied up.

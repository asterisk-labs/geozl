GeoZL in Zarr

  • Python · CPU
  • Open in Colab
  • Notebook on GitHub

Zarr stores an array as a grid of chunks and runs each chunk through a list of codecs. This notebook puts GeoZL in that list, writes a Copernicus DEM tile with it, reads it back with xarray in one line, and times the read against Zarr's default zstd.

The notebook has four parts: the codec, the write, the read, and the read speed. The write and the read are independent: a reader needs the store and the codec, nothing else.

The codec

A Zarr v3 array lists its codecs in zarr.json. The first one turns the chunk array into bytes; by default that is bytes, a plain memory copy, followed by zstd. GeoZL replaces both: it reads the chunk as a raster and writes one GeoZL frame.

A frame stores bytes, not the dtype or the shape. Zarr already knows both from the array metadata and passes them to the codec with every chunk, so nothing extra is stored. The only setting is the recipe, which goes into zarr.json.

The default recipe is planar>zigzag>lanes. On this DEM, geozl.profile puts it within 2% of the best ratio, and it decodes about four times faster than planar>zigzag>entropy, the recipe with the best ratio. Pass GeoZLCodec(method=...) to use any row of profile.

Two details matter:

  • Decoding needs no graph. geozl.decompress reads the frame on its own. max_output_size caps it at the chunk size, because a store is untrusted input.
  • Encoding needs a graph, and a Graph is not thread-safe. Zarr encodes and decodes chunks on a thread pool, so each thread builds and keeps its own. Zarr pads the edge chunks to the full chunk shape, so one graph per dtype covers the whole array.

This is lossless. A lossy recipe would also need its domain in the configuration, which this example leaves out.

GeoZLCodec

import asyncio
import threading
from dataclasses import dataclass

import numpy as np
from zarr.abc.codec import ArrayBytesCodec
from zarr.registry import register_codec

_local = threading.local()


@dataclass(frozen=True)
class GeoZLCodec(ArrayBytesCodec):
    """Lossless GeoZL in place of Zarr's `bytes` codec."""

    method: str = "planar>zigzag>lanes"
    is_fixed_size = False

    @classmethod
    def from_dict(cls, data):
        return cls(**data.get("configuration", {}))

    def to_dict(self):
        return {"name": "geozl", "configuration": {"method": self.method}}

    def _graph(self, chunk):
        graphs = _local.__dict__.setdefault("graphs", {})
        key = (self.method, chunk.dtype.str, chunk.shape)
        if key not in graphs:
            graphs[key] = geozl.graph(chunk, self.method)
        return graphs[key]

    def _encode_sync(self, chunk_array, chunk_spec):
        chunk = np.ascontiguousarray(chunk_array.as_numpy_array())
        frame = geozl.compress(chunk, graph=self._graph(chunk))
        return chunk_spec.prototype.buffer.from_bytes(frame)

    def _decode_sync(self, chunk_bytes, chunk_spec):
        dtype = chunk_spec.dtype.to_native_dtype()
        nbytes = int(np.prod(chunk_spec.shape)) * dtype.itemsize
        out = geozl.decompress(chunk_bytes.as_numpy_array(), max_output_size=nbytes)
        arr = out.view(dtype).reshape(chunk_spec.shape)
        return chunk_spec.prototype.nd_buffer.from_numpy_array(arr)

    async def _encode_single(self, chunk_array, chunk_spec):
        return await asyncio.to_thread(self._encode_sync, chunk_array, chunk_spec)

    async def _decode_single(self, chunk_bytes, chunk_spec):
        return await asyncio.to_thread(self._decode_sync, chunk_bytes, chunk_spec)

    def compute_encoded_size(self, input_byte_length, chunk_spec):
        raise NotImplementedError


register_codec("geozl", GeoZLCodec)

Write

to_zarr writes the DataArray with its coordinates. The encoding picks the chunk shape and the codecs for the elevation variable; the coordinates keep Zarr's defaults.

Two stores, same chunks: one with GeoZL, one with Zarr's default (bytes then zstd at level 0).

import shutil

CHUNKS = (512, 512)
STORES = {
    "geozl": {"serializer": GeoZLCodec(), "compressors": None},
    "zstd": {},
}

for name, codecs in STORES.items():
    path = Path(f"dem_{name}.zarr")
    shutil.rmtree(path, ignore_errors=True)
    da.to_dataset().to_zarr(path, zarr_format=3, consolidated=False,
                            encoding={"elevation": {"chunks": CHUNKS, **codecs}})
    print("wrote", path)

Read speed: GeoZL vs zstd

The clock should see decoding, not the disk or the network. Each array is copied into a MemoryStore first, and the timed call reads the whole array from there with plain Zarr, best of seven. Speed is raw megabytes delivered per second.

The reads use Zarr's FusedCodecPipeline, which takes a thread count: codec_pipeline.max_workers. The table reads the array once on one thread and once on every core. The default pipeline picks its own threads, so it cannot show the one-thread case.

import os
import time

import pandas as pd
from zarr.storage import MemoryStore

THREADS = os.cpu_count()
FUSED = "zarr.core.codec_pipeline.FusedCodecPipeline"


def to_memory(name):
    src = zarr.open_array(f"dem_{name}.zarr/elevation", mode="r")
    dst = zarr.create_array(MemoryStore(), shape=src.shape, chunks=src.chunks,
                            dtype=src.dtype, **STORES[name])
    dst[:] = src[:]
    return dst.store


def best_read(store, workers, reps=7):
    with zarr.config.set({"codec_pipeline.path": FUSED,
                          "codec_pipeline.max_workers": workers}):
        z = zarr.open_array(store, mode="r")
        z[:]
        best = float("inf")
        for _ in range(reps):
            t = time.perf_counter()
            z[:]
            best = min(best, time.perf_counter() - t)
    return best


rows = []
for name in STORES:
    store = to_memory(name)
    for workers in (1, THREADS):
        s = best_read(store, workers)
        rows.append({"codec": name, "threads": workers, "ratio": da.nbytes / size[name],
                     "read ms": s * 1e3, "read MB/s": da.nbytes / 1e6 / s})

speed = pd.DataFrame(rows)
speed.round(2)

How much of the read is Zarr

A Zarr read does more than decode: it fetches each chunk from the store, calls the codec through Python, and copies the chunk into the output array. To see the codec alone, take the stored chunks out of the store and decode them in a loop, on one thread.

import numcodecs

src = {name: Path(f"dem_{name}.zarr/elevation/c") for name in STORES}
frames = {name: [f.read_bytes() for f in sorted(d.rglob("*")) if f.is_file()]
          for name, d in src.items()}
zstd = numcodecs.Zstd()
decode = {"geozl": lambda f: geozl.decompress(f, verify=False), "zstd": zstd.decode}

alone = []
for name in STORES:
    raw = len(frames[name]) * CHUNKS[0] * CHUNKS[1] * dem.itemsize
    best = float("inf")
    for _ in range(7):
        t = time.perf_counter()
        for f in frames[name]:
            decode[name](f)
        best = min(best, time.perf_counter() - t)
    zarr_1 = speed.query("codec == @name and threads == 1")["read MB/s"].item()
    alone.append({"codec": name, "codec alone MB/s": raw / 1e6 / best,
                  "Zarr read, 1 thread MB/s": zarr_1})

pd.DataFrame(alone).round(0)

Speeds depend on the machine and its SIMD path, so compare rows from one run only. A free Colab runtime has two cores.

What this example does not cover

  • Lossy recipes. graph() takes the lossy domain from the raster it is built on. A Zarr codec builds its graph per chunk, so the domain would have to live in the codec configuration.
  • Readers without the codec. Any reader must have GeoZLCodec registered; other Zarr implementations cannot open the store.

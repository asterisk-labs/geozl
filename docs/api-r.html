The R package has the graph, compress, decompress and profile calls of the Python package and writes the same frames. It works on the double, integer and raw vectors that terra and stars hold.

Install

install.packages("geozl", repos = "https://asterisk-labs.r-universe.dev")

# or from GitHub
remotes::install_github("asterisk-labs/geozl", subdir = "bindings/r")

A source install compiles GeoZL and OpenZL with their own CMake files, so it needs CMake 3.21 or newer and C11 and C++17 compilers. webR is still not supported.

library(geozl)

tile <- outer(1:256, 1:256, function(x, y) 1000 + 3 * (x - 1) + 2 * (y - 1))

rows <- geozl_profile(tile, datatype = "uint16")
g <- geozl_graph(tile, rows$graph[[1]], datatype = "uint16")
frame <- geozl_compress(tile, g)
back <- geozl_decompress(frame, "uint16", dim = dim(tile))
identical(back, tile)                        # TRUE

Functions

Every exported function is below. Bad arguments and a frame or recipe the library refuses stop with an R error.

geozl_profile

geozl_profile(x, prior = "planar", width = NULL, planes = NULL,
    error = NULL, reps = 5L, nodata = NULL, datatype = NULL,
    verify = FALSE)

Compresses and decompresses x with every recipe the prior allows and ranks them by compression ratio. Recipes that do not apply to the input are left out.

priorOne predictor plus the id path, "planar", "med", "delta_w", "delta_n", "average", "wp_static" or "delta_1d". NULL tries every predictor and "none" only id.
repsRound trips per recipe, at least 1. The fastest is kept.
verifyCheck checksums while timing decode. The frames carry them either way.
othersAs in geozl_graph.

Returns a geozl_profile data frame, best ratio first, with the columns graph, bytes, ratio, encode_mbps, decode_mbps and shannon_pct. print shows the input and settings above the table.

rows <- geozl_profile(tile, prior = NULL, datatype = "uint16", reps = 1)
rows$graph[[1]]                              # "med>zigzag>zstd"

geozl_graph

geozl_graph(x, method, width = NULL, planes = NULL, error = NULL,
    nodata = NULL, datatype = NULL)

Builds a reusable graph for one recipe. The graph fixes the recipe, the storage type and the geometry of every tile compressed with it.

xA double, integer or raw vector or array. For a bounded-error graph it fixes the domain later tiles are checked against, so use data spanning the product.
methodA recipe as geozl_profile spells it, such as "planar>zigzag>pfor". Python's graph lists them all.
widthRow length in samples. Defaults to dim(x)[1] and is required for a vector without dim.
planesStacked images predicted independently. Defaults to the last dimension of an array with three or more, otherwise 1.
errorNULL or 0 for lossless, a number for an absolute bound, "1%" for a relative bound, or a full LINEAR, LOG or SQRT recipe, as in Python.
nodataA sentinel for missing samples. NA and NaN in x are stored as it. NaN selects NaN handling, which a float raster with missing values gets without asking.
datatypeThe storage type, as numpy ("uint16"), terra ("INT2U") or GDAL ("UInt16") names it, for 8 to 64 bit integers and 16 to 64 bit floats. Defaults to "int32" for integer, "float64" for double and "uint8" for raw input.

Returns a geozl_graph with the fields method, width, planes, datatype, error and nodata. It wraps native state, so it is not thread safe and does not survive saving and reloading.

Samples are converted to datatype first. Integer types refuse values that are not whole or do not fit, and float types round to nearest. A raw vector is taken as native samples of datatype already.

g <- geozl_graph(tile, "planar>zigzag>pfor", error = 2, datatype = "uint16")
g$error                                      # "LINEAR:MAX_ERROR=2"

geozl_compress

geozl_compress(x, graph, coeffs = NULL)

Compresses one tile with a graph and returns the frame as a raw vector. x is converted to the graph's datatype, and its geometry is not checked against the graph.

graphA graph from geozl_graph.
coeffsA list of integer vectors stored in the frame header, read back with geozl_coeffs. GeoZL gives them no meaning.
frame <- geozl_compress(tile, g, coeffs = list(c(1L, 2L, 3L), 4L))

geozl_decompress

geozl_decompress(frame, datatype = NULL, dim = NULL, as = NULL,
    nodata = NULL, verify = TRUE, max_output_size = NULL)

Decodes a frame. The frame stores no datatype or shape, so pass the ones it was written with.

datatypeThe storage type of the frame. Without it the result is the raw native bytes.
dimDimensions for the result, in samples.
as"double", the default with a datatype, "integer", or "raw" for the native bytes, which torch reads without a copy through torch_tensor_from_buffer().
nodataSamples equal to this value become NA.
verifyCheck the frame checksums.
max_output_sizeRefuse a frame that declares more output bytes than this. Set it for untrusted frames.
back <- geozl_decompress(frame, "uint16", dim = dim(tile), as = "integer")

geozl_coeffs

geozl_coeffs(frame)

Returns the coefficient vectors stored by geozl_compress as a list of integer vectors, or NULL when the frame has none. Only the frame header is read.

geozl_coeffs(frame)                          # list(c(1L, 2L, 3L), 4L)

Rasters

The fastest-varying dimension is the row. An array shaped (x, y) or (x, y, band), as stars holds a raster, gives the same frame as Python does for (y, x) or (band, y, x).

The matrix from terra::values(r) is shaped (ncell, nlyr), so pass width = terra::ncol(r), planes = terra::nlyr(r). terra::as.array() is (y, x, band), so pass it through aperm(a, c(2, 1, 3)) first.

R stores NA and NaN as the nodata sentinel, where Python leaves NaN in the samples. A lossless float64 frame keeps NA and NaN apart. float32 and float16 store both as one NaN, so NA reads back as NaN.

What it covers

The R package covers profile, graph, compress, decompress and coeffs. It has no OpenZL nodes like geozl.lossless and geozl.lossy, no fit_noise and no GPU decode. A SQRT recipe without A= and B= is fitted on the raster given to geozl_graph. To share one curve across products, fit it in Python with fit_noise and pass the recipe it writes.

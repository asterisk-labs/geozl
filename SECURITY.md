# Security

## Supported versions

Security fixes are made against the latest release.

## Reporting a vulnerability

Please do not open a public issue. Email `hello@asterisk.coop` with
`[geozl security]` in the subject. Include the affected version, platform,
impact and a reproducer or sample frame when possible.

Malformed frames that cause crashes, invalid memory access, hangs or excessive
resource use are security issues. If you are unsure, report the finding
privately and we will assess it with you.

We will coordinate a fix and public disclosure with the reporter. Credit is
given unless anonymity is requested.
